> **PlantTwin AI™ Backend** is an enterprise-grade API gateway, time-series telemetry ingestion engine, and AI predictive service built with FastAPI, SQLAlchemy 2.0 Async ORM, PostgreSQL 14, TimescaleDB, and Redis.

---

## 🛠 Features & Architecture Modules

- 🔐 **Identity & Authentication (`/api/v1/identity/auth`)**: Real signed JWT access & refresh token authentication with bcrypt password hashing.
- 👥 **User Management & RBAC (`/api/v1/identity/users`)**: Multi-tenant role-based access control (System Admin, Plant Manager, Reliability Engineer, Control Operator).
- 🏢 **Multi-Tenant Organizations (`/api/v1/enterprise/organizations`)**: Multi-organization tenant isolation and subscription tier management.
- 🌳 **ISA-95 Hierarchy (`/api/v1/enterprise/plants`)**: Enterprise $\rightarrow$ Site $\rightarrow$ Area $\rightarrow$ Production Line topology hierarchy.
- ⚙️ **Asset & Equipment Services (`/api/v1/assets/equipment`)**: Equipment master data management and sensor tag registration.
- 🚨 **Runtime Alarms & Operations (`/api/v1/runtime/alarms`)**: ISA-18.2 compliant alarm state machine (Unacknowledged, Acknowledged, Shelved, Cleared).
- 📋 **Work Orders Engine (`/api/v1/runtime/work-orders`)**: Preventive & corrective maintenance work order pipeline.
- 🔔 **Notification Gateway (`/api/v1/notifications/center`)**: Multi-channel notification delivery and escalation matrix routing.
- 🛡️ **Audit Log Stream (`/api/v1/identity/audit`)**: Append-only audit logging tracking all administrative interventions and PLC memory writes.

## ⚡ Quick Start

```bash
# 1. Create and activate Python virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 2. Install requirements
pip install -r requirements.txt

# 3. Start development server
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
